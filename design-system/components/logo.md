# logo

> Layer: Commerce · Status: placeholder · Figma: [DKB Commerce › logo](https://www.figma.com/design/0xda5d6a7EF5fo2Yiqh91S?node-id=2-1058)

## Purpose
The brand mark in headers, footers and auth pages. Today a text wordmark «دیجی‌کالا بیزینس» in `text.primary`; it becomes the official logo SVG when the asset is added to the repo, and every header, footer and template updates.

## Properties
| Property | Type | Values | Default | Notes |
|---|---|---|---|---|
| `size` | variant | `md`, `sm` | `md` | md: desktop header, footer, auth; sm: mobile header and footer |

## Tokens
`md`: `heading-4`, `sm`: `label`; colour `text.primary` (follows the brand mode).

## Accessibility
Links to home; accessible name «دیجی‌کالا بیزینس».
