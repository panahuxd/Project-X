# logo

> Layer: Commerce · Status: draft · Figma: [DKB Commerce › logo](https://www.figma.com/design/0xda5d6a7EF5fo2Yiqh91S?node-id=2-1058)

## Purpose
The official brand mark in headers, footers and auth pages, from the brand file *VA - DKB Logos* (Persian, horizontal, primary colour). Never redraw, stretch or recolour it by hand; change it here and every header, footer and template updates.

## Properties
| Property | Type | Values | Default | Notes |
|---|---|---|---|---|
| `size` | variant | `md`, `sm` | `md` | md: smile + «دیجی‌کالا بیزینس», 28 high (desktop header, footer, auth); sm: wordmark only, 20 high (mobile header and footer) |

## Tokens
One flattened vector `logo-mark`, fill bound to `text.primary`: #093672 in B2R (the official primary colour); in B2E it follows the brand (violet). Other official versions (red, white, English, vertical) stay in the brand file until a surface needs them, e.g. white on a dark hero.

## Accessibility
Links to home; accessible name «دیجی‌کالا بیزینس».
